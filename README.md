# Minishell

셸 스크립트 ( bash ) 의 간단한 기능을 구현한다.

## 1. 프로젝트 설명

셸(bash) 의 기본적인 기능을 구현하고, 멀티프로세싱을 통해 다중파이프 연결을 처리한다. 
키보드 입력 시그널을 처리하고, 예외처리를 구현한다. 

### 목표

- 셸 기본 명령어의 작동
- 다중 파이프로 연결된 명령어의 동시성 확보
- 시그널 (ctrl+d , ctrl+c, ctrl+\) 발생시 시그널 커맨드 실행
- 명령어 별 에러시 종료코드 반환 

### 상세 기능

- ./minishell 명령어를 통해 셸에 입장하여 기존의 셸과 동일하게 사용 가능


### 제작 기간

23.11 ~ 23.12
